# OpenAI Assistant API Chatbot 🤖  

### A Virtual Text Assistant Powered by OpenAI APIs, Python Flask, and LLM  

This project creates a human-like virtual assistant using state-of-the-art Language Models (LLMs) from OpenAI. The assistant is built with Python Flask to handle backend processes and seamlessly integrates OpenAI APIs to deliver intelligent, conversational capabilities.

---

## ✨ Features  

- **Conversational AI**:  
  Leverages OpenAI's advanced LLM for natural and meaningful text-based conversations.  

- **Flask Backend**:  
  A lightweight and efficient backend built with Python Flask to manage API calls and user interactions.  

- **API Integration**:  
  Fully integrated with OpenAI APIs to ensure robust and scalable AI-powered interactions.  

- **Customizable Assistant**:  
  Tailor the assistant's behavior, tone, and responses to suit specific use cases.  

- **User-Friendly Interface**:  
  A clean and intuitive web-based interface for seamless interaction with the assistant.  

---

## 🛠️ Technology Stack  

- **Backend**: Python Flask  
- **Frontend**: HTML & JavaScript  
- **APIs**: OpenAI APIs  
- **Other Tools**:  
  - Flask-CORS for cross-origin requests  
  - Requests library for API integration

## 🚀 Getting Started  

Follow these steps to set up and run the project locally:  

### 1. Prerequisites  

- **Python**: Version 3.8 or above  
- **OpenAI API Key**: Obtain a key from [OpenAI](https://platform.openai.com/)  

### 2. Installation  

1. **Clone the Repository**:  
   ```bash  
   git clone https://github.com/kneeraazon404/openai-assistant-api-chatbot.git  
   cd openai-assistant-api-chatbot  
   ```  

2. **Set Up a Virtual Environment**:  
   ```bash  
   python -m venv env  
   source env/bin/activate  # On Windows: env\Scripts\activate  
   ```  

3. **Install Dependencies**:  
   ```bash  
   pip install -r requirements.txt  
   ```  

### 3. Configuration  

1. **Environment Variables**:  
   Create a `.env` file to store your OpenAI API key:  
   ```env  
   OPENAI_API_KEY=your_openai_api_key_here  
   ```  

2. **Flask Configuration**:  
   Ensure Flask is configured to run in development mode by setting the `FLASK_ENV` variable:  
   ```bash  
   export FLASK_ENV=development  # On Windows: set FLASK_ENV=development  
   ```  

---

## ⚙️ Running the Application  

Start the Flask application:  
```bash  
python app.py  
```  

The application will be accessible at `http://127.0.0.1:5000`.
